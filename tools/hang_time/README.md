# 체공시간으로 타구속도·발사각 추정 검증

발사각과 타구속도를 잴 장비가 없을 때, 화면에서 찍은 낙구 거리와 직접 잰 체공시간으로 뜬공·라이너의 발사각과 타구속도를 얼마나 추정할 수 있는지 확인한 분석이다.

## 방법

1. 공기저항과 회전(Magnus)을 넣은 2차원 궤적 모델을 MLB Statcast 공개 데이터(Baseball Savant)로 보정한다. 타구속도·발사각을 넣으면 비거리와 체공시간이 나온다.
2. 보정에 쓰지 않은 날짜의 타구로 비거리 예측을 검증한다.
3. 같은 타구들에 대해 "관측값"을 만든다: 비거리 = Statcast 비거리 + 낙구 탭 오차, 체공시간 = 모델 체공시간 + 스톱워치 오차. 이 두 값으로 격자 탐색해 타구속도·발사각을 거꾸로 추정하고 실제 값과 비교한다. 비거리만 쓴 추정과도 비교한다.

Statcast CSV에는 체공시간이 없어서 3번의 체공시간은 모델 값이다. 실제로 잰 체공시간과 모델의 차이는 이 분석에 들어 있지 않다.

## 결과 (2025-06-01~10, 뜬공·라이너 3,295개, 앞 절반으로 보정·뒤 절반으로 검증)

- 비거리 예측(타구속도·발사각 → 비거리): 평균 절대 오차 4.7m, RMSE 6.0m.
- 거꾸로 추정 (낙구 탭 오차 σ, 스톱워치 오차 σ):

| 탭 σ | 스톱워치 σ | 타구속도 오차 | 발사각 오차 | 비거리만 쓸 때 | 강한 타구(≥95mph) 구분 | 발사각 구간 구분 |
| --- | --- | --- | --- | --- | --- | --- |
| 3m | 0.1s | 5.3mph | 1.7° | 7.0mph · 9.7° | 84% (비거리만 72%) | 91% (39%) |
| 5m | 0.2s | 5.9mph | 2.3° | 7.0mph · 9.9° | 82% (72%) | 87% (39%) |
| 5m | 0.3s | 6.1mph | 2.6° | 7.0mph · 9.8° | 81% (71%) | 85% (39%) |
| 8m | 0.3s | 6.8mph | 3.1° | 7.1mph · 9.8° | 80% (71%) | 84% (39%) |
| 5m | 0.5s | 6.7mph | 3.6° | 7.0mph · 9.9° | 77% (73%) | 78% (39%) |

발사각 구간: 20° 미만 / 20~32° / 32° 초과.

읽는 법:
- 체공시간은 발사각을 크게 살린다. 비거리만으로는 발사각을 거의 모르지만(오차 약 10°), 체공시간을 0.3초 안팎으로 재면 오차가 2~3°로 줄고 라이너·뜬공·높은 뜬공을 85% 안팎으로 가른다.
- 타구속도는 조금 나아진다(7.0 → 6mph 안팎). 강한 타구 구분은 71% → 81% 정도.
- 대상은 외야까지 간 뜬공·라이너(발사각 8~60°, 비거리 45m 이상)뿐이다. 땅볼에는 쓸 수 없다.

## 실행

```sh
python3 -m venv .venv && .venv/bin/pip install numpy scipy
mkdir data   # Baseball Savant의 statcast_search CSV(type=details)를 날짜별로 받아 넣는다. 저장소에는 넣지 않는다
.venv/bin/python model.py data
```

## 실측 체공시간으로 확인하기

위 표의 체공시간은 모델 값이라, 사람이 영상을 보며 잰 체공시간으로 같은 계산을 해 봐야 한다. `make_timing.py`가 그 측정 페이지를 만든다.

```sh
.venv/bin/python make_timing.py data 30   # out/timing.html: 뜬공·라이너 30개 (발사각 구간별로 고름)
open out/timing.html
```

- 각 플레이의 중계 영상을 Baseball Savant의 영상 페이지에서 그대로 띄운다(영상 부분만 보이게 잘라서). 그 페이지 옆 칸의 타구속도·비거리는 가려진다.
- 타격 순간과 공이 땅에 닿거나 잡히는 순간에 큰 버튼(또는 `Space`)을 누른다. 경기를 보며 앱에서 재는 것과 같은 실시간 스톱워치다.
- 10개 이상 재면 `결과 보기`로 내 체공시간과 모델 체공시간의 차이, 그리고 (Statcast 비거리, 내 체공시간)으로 추정한 타구속도·발사각의 오차가 나온다. 비거리만 쓴 추정과 나란히 보여 준다.
- 잡힌 타구는 포구 높이(1.8m)까지의 시간으로 비교한다.
- 영상과 Statcast 수치가 담긴 `out/`은 저장소에 넣지 않는다.

페이지 자체 점검: 모델 체공시간을 그대로 넣으면 발사각 오차 1.0°·구간 일치 93%, 0.18초 잡음을 넣으면 1.9°·87%가 나와 위 시뮬레이션과 맞는다.
